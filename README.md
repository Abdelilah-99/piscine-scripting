# Scripting piscine: Bash and Python

My solutions to the **Zone01 scripting piscine**: about 60 small exercises in **Bash** and
**Python** covering everyday DevOps and automation tasks.

## Topics
| Area | Examples |
| --- | --- |
| Files and permissions | `find-files.sh`, `count-files.sh`, `easy-perm.sh`, `hard-perm.sh`, `file-details.sh` |
| Text and streams | `head-and-tail.sh`, `skip-lines.sh`, `input-redirection.sh`, `append-output.sh` |
| Variables and environment | `set-env-vars.sh`, `set-internal-vars.sh`, `env-format.sh` |
| Conditions and arithmetic | `easy-conditions.sh`, `hard-conditions.sh`, `calculator.sh`, `division.sh` |
| Processes and jobs | `in-back-ground.sh`, `auto-jobs.tar`, `bin-status.sh` |
| JSON and data | `json-researcher.sh`, `object_to_json.py`, `credentials_searches.py` |
| Python basics | `string_processing.py`, `numerical_operations.py`, `read_file.py`, `write_file.py` |

## Run an exercise
```bash
bash hello-devops.sh
python3 hello_python.py
```

**Stack:** Bash · Python
